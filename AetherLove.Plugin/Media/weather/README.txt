Weatherman icon set
===================

Drop one PNG per file name below into this folder (transparent background,
square, 128x128 or larger; flat style works best). The app picks them up on
the next plugin load; any missing file falls back to the game's own weather
icon, so partial sets are fine.

Every FFXIV weather is classified into one of these families (English sheet
names; localized clients map identically). Suggested Flaticon search terms
are listed per file.
