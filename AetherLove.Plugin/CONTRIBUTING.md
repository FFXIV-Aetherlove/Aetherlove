# Contributing

## Development home
Active development happens on our *private* GitLab repository. This GitHub repository is a mirror that only contains the client. Pull requests opened here will not be merged — with one exception: translation corrections (see below).

## Translations
Translation fixes and improvements are always welcome and do not require prior discussion. If you spot an incorrect or awkward translation in any of the six supported languages (English, German, French, Spanish, Portuguese, Russian), open a pull request here on GitHub with the correction. These will be reviewed and backported into the main codebase.

Translations live in `AetherLove.Plugin/Services/Localization/Strings/`.

## Feature requests
New feature ideas are discussed on the community Discord. You can find the invite link at https://aetherpool.space. Please open a request there before working on anything substantial — it avoids duplicating effort with work already in progress on the private branch.
